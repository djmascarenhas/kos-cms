# KOS CMS

Portal institucional e plataforma de inteligência técnico-institucional do Conselho Municipal de Saúde de Chapada dos Guimarães - MT.

## Desenvolvimento local

- CMS: http://localhost:3000
- KOS: http://localhost:3001

Inicie o CMS com `npm run dev:cms` e o KOS com `npm run dev:kos`.

## Estrutura

- `apps/cms` — portal institucional
- `apps/kos` — inteligência técnico-institucional
- `packages` — módulos compartilhados futuros

O KOS é uma ferramenta de apoio técnico-institucional e não substitui as deliberações do Conselho Municipal de Saúde.
